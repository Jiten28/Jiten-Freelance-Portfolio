# Jiten Creative Co. Menu Template Library

Seven premium normal menu/service price-list template systems. Each includes A4 PNG, mobile PNG, portfolio preview PNG and reusable Markdown prompt. Use client content, logo, photos, colors, prices and business information as source of truth. Do not invent missing information; use placeholders or request it.

Templates: Modern Cafe, Premium Restaurant, Minimal Contemporary, Modern Indian Restaurant, Laundry & Dry Cleaning, Salon & Beauty, Local Service Business.
